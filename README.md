# Kidsense - Application Interactive Éducative pour Enfants et Parents

Kidsense est une application web innovante qui combine **jeux éducatifs**, **histoires interactives** et **missions ludiques** pour aider les enfants à apprendre tout en s’amusant. Elle propose également aux **parents** un tableau de bord pour suivre les progrès de leurs enfants et mieux comprendre leurs centres d’intérêt et leurs forces.

## Fonctionnalités

### Côté Enfant
- Interface colorée, intuitive et amusante
- Jeux éducatifs :
  - **Mathématiques** (Match, Count, Logique, Pattern)
  - **Dessin**
  - **Géométrie**
- Histoires personnalisées avec chapitres immersifs
- Missions à débloquer pour stimuler la curiosité

### Côté Parent
- Interface dédiée aux parents
- Inscription des enfants par tranche d’âge
- Suivi des progrès de l’enfant (dashboard)

##  Technologies utilisées

- Frontend : React + Tailwind CSS
- Backend: Node.js + Express
- Base de données: MongoDB (Mongoose)
- Authentification : JWT
- Outils : Postman, Nodemon
